# CozyCrazyZones 0.3.26 active ecology

0.3.25 established the Danger Bible as a NATURAL-spawn filter. 0.3.26 adds the positive population layer and closes two pre-remap leakage paths.

## Spawn paths

- `MobSpawnType.NATURAL`: runtime natural spawning. CozyCrazyZones may replace a controlled share of vanilla candidate selections with regional candidates through `NaturalSpawnerMixin`.
- `MobSpawnType.CHUNK_GENERATION`: initial passive wildlife populated when terrain is generated. This path is filtered by the same geography firewall so inherited/native biome tags cannot seed Sunscar elephants or other strongly regional wildlife into the neutral shared core.
- Structure, spawner, summoned, raid and authored event spawn types are not treated as ambient ecology and intentionally bypass this layer.

The positive layer does not create a periodic spawner and does not add spawn attempts. It reuses vanilla attempts, mob caps, and candidate validation. Dynamically selected entries bypass only vanilla's requirement that the exact `SpawnerData` object already exist in the static biome list; vanilla SpawnPlacements, light, collision and obstruction checks still run.

## Shared core

The inner shared core has no cardinal spawn injection. `RegionalWildlifePolicy` additionally rejects strongly regional fauna there, including dry/savanna, tropical and cold-specialist animals even if an earlier TerraBlender/native biome injected them before the final visible biome was remapped.

`RegionalStructureSemanticPolicy` performs the analogous fallback for structures whose IDs reveal a strong regional variant. Audited hidden-semantic IDs such as `dungeons_enhanced:tree_house` are explicitly classified even though their registry path does not contain the word `jungle`.

## Performance

No periodic entity scans, radius searches, remote locates, or extra mob-cap load are introduced. Special/E4 selections use in-memory 512-block cooldown buckets.
